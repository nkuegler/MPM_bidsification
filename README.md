# Bidsification of the IronSleep MRI data

This repository contains the code to bidsifiy a set of MRI data. First, the DICOM-to-NIfTI conversion can be performed optionally using the scripts provided in this repository. Thereafter, the DICOM-imported NIfTI data is bidsified using [Bidsme](https://github.com/CyclotronResearchCentre/bidsme). You can find a detailed documentation of the different functionalities and how to use them in the [docs/ directory](docs/) of this repository (contains documentation of [DICOM-to-NIfTI conversion](docs/doc_DICOM-to-NIfTI.md) and [Bidsification](docs/doc_bidsification.md)). Feel free to [reach out to me](mailto:kuegler@cbs.mpg.de?subject=Problems%20with%20MPM_bidsification) if you encounter any problems. 

> The two processing steps are part of a larger data processing pipeline, designed to automatically analyze the MRI data acquired in the [IronSleep](https://www.cbs.mpg.de/neurophysics/third-party-funding/ironsleep) project. Documentation of the whole pipeline is available in the [MPI CBS Neurophysics Confluence Wiki](https://confluence.mpg.de/x/jgcqAw) _(restricted access)_.
